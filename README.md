# 🌠 Neon Duel Arena

**Neon Duel Arena** is a stunning, fast-paced 2-player local multiplayer spaceship battle game built entirely with HTML5, CSS3, and modern Vanilla JavaScript. Grab a friend, share a keyboard, and battle it out in a glowing cyberpunk arena!

## ✨ Features
- **Fast-paced Local Multiplayer:** Duel against your friend on the same keyboard in a smooth 60FPS battle.
- **Dynamic Cyberpunk Aesthetics:** Beautiful neon glowing elements, vibrant particle explosions, and smooth glassmorphism UI.
- **Abilities & Power-ups:** Use Shields, Dash abilities, Rapid Fire, Spread Shots, Speed boosts, and Health orbs.
- **Persistent Leaderboard:** Player ranks and win records are automatically saved in the browser.
- **Customizable Battles:** Adjust the required rounds to win, arena size, and power-up spawn rates in the settings!

## 🎮 How to Play

The game requires two players on a single keyboard. First to win the set number of rounds takes the crown!

### Player 1 (Cyan Ship)
- **Move:** `W` `A` `S` `D`
- **Shoot:** `SPACE`
- **Dash:** `E`
- **Shield:** `Q`

### Player 2 (Magenta Ship)
- **Move:** `Arrow Keys` (↑ ← ↓ →)
- **Shoot:** `ENTER`
- **Dash:** `/`
- **Shield:** `Right SHIFT`

*(Both players can press **ESC** to easily pause the game!)*

## 🚀 How to Run Locally

You don't need to install any heavy packages or build tools to run Neon Duel Arena! 

1. **Clone this repository** to your local machine:
   ```bash
   git clone https://github.com/Natnael2124/neon-dual-arena.git
   ```
2. **Navigate into the folder**:
   ```bash
   cd neon-dual-arena
   ```
3. **Start a local web server**. If you have Python installed, you can simply run:
   ```bash
   python3 -m http.server 8080
   ```
4. **Play!** Open your web browser and go to: `http://localhost:8080`

*Alternatively, you can just double-click the `index.html` file to open it in your browser immediately!*
